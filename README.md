# NewsApp
This application is for learning the different functions in android kotlin 
<br>
This application has been coded using a news playlist from youtube and taught me the basics of how an application stores data and 
also how it pulls data when required .
<br>

The application uses:
1. API Key to Load the News from the web
2. Room DataBase to save the bookmarked news and load them
3. Navigation to switch between tabs

The Application has:
1. Home Screen
2. Search Screen
3. BookMarked Screen
4. Live Score for a particular sport

The application allows the user to bookmark news they want to read later , Read more about their choice of news and also allows them to visit their
choice of news to the source.
The application also allows the user to share news to their friends and family.
It also allows them to search or look up their favourite genre and see whats going on in that particular topic.
